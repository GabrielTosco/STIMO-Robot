# STIMO Robot

## Overview

STIMO (Student Technology for Interactive Modes and Operations) is an IoT-based robotic assistant developed as a Computer Engineering Capstone Thesis. The project was built using Python and Raspberry Pi 4 to integrate hardware and software for interactive automation and intelligent assistance.

---

## Features

- Voice interaction
- IoT connectivity
- Automation
- Hardware and software integration
- Real-time device interaction

---

## Technologies Used

- Python
- Raspberry Pi 4
- Raspberry Pi OS

## Source Code

The `source-code` folder contains the core Python files used in the development of STIMO.

### Main Modules

- **main.py** – Main program that initializes and manages the STIMO system.
- **calendar.py** – Handles calendar scheduling and reminder functionalities.
- **fingerprint.py** – Implements fingerprint authentication and user verification.
- **gaming.py** – Provides the gaming mode and interactive entertainment features of STIMO.
