# STIMO Robot

**An IoT-based robotic assistant built with Python and Raspberry Pi 4 for student-focused assistance, interactive activities, and everyday computing.**

Developed as a **Computer Engineering capstone thesis at STI College Kalibo**.

**Tech stack:** Python · Raspberry Pi 4 · Raspberry Pi OS · IoT · Embedded systems

![STIMO robot front view](stimo_front.jpg)

## Project overview

**STIMO** stands for **Student Technology for Interactive Modes and Operations**. It combines hardware and software into a multifunctional robotic assistant designed to support learning, interaction, and automation.

The project integrates **Speech-to-Text (STT)** and **Text-to-Speech (TTS)** capabilities, provides student assistance features connected to STI's eLMS platform, and offers several operating modes.

## Operating modes

| Mode | Purpose |
| --- | --- |
| **STIMO Mode** | Voice-based student assistance, academic reminders, eLMS integration, and automation features |
| **PC Mode** | General-purpose computing tasks through a conventional desktop environment |
| **Game Mode** | Interactive educational and entertainment activities |

## Technical highlights

- Integrated Raspberry Pi hardware with Python-based software.
- Combined speech recognition and voice output for interactive assistance.
- Built a multi-mode interface for academic support, computing, and games.
- Included fingerprint authentication and scheduling modules in the project code.
- Developed and tested the prototype as part of a collaborative capstone project.
